KISHIKA BALACHANDAR — PORTFOLIO WEBSITE

FILES
- index.html: Complete responsive portfolio website (HTML, CSS, and JavaScript are included).
- kishika-balachandar.png: Profile photo.
- Resume.pdf: Downloadable resume used by the button on the website.

RUN LOCALLY
1. Extract this ZIP folder.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html. For the best experience, right-click and choose Open with Live Server.
